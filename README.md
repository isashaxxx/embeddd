# embeddd

MVP доски в стиле Pinterest/bento: masonry-сетка карточек трёх размеров и красивые превью ссылок.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173 — это лендинг; само приложение живёт по адресу `#/recent`.

## Что умеет

- **Лендинг** в стиле cosmos.so: шапка со строкой «вставь ссылку» (создаёт доску с этой ссылкой), hero с 3D-полем летающих карточек, живая демо-доска на настоящих компонентах, анимированная витрина ссылок, фичи, секция со sticky-скроллом, бегущая строка интеграций, финальный CTA и гигантский вордмарк. Фото в `public/landing/` взяты с Unsplash (Unsplash License).
- **Как в Figma:** сайдбар есть на всех страницах, включая доску. Разделы Recents, Drafts, Projects, Achievements, Trash. Плитки досок показывают уменьшенную раскладку, есть поиск и сортировка.
- **Доски:** создать, переименовать, дублировать, перенести в проект (меню или перетаскивание на проект), удалить в Trash с кнопкой Undo. Сетка на выбор — 4, 6 или 8 колонок, настройка у каждой доски.
- **Карточки:** размеры S/M/L, перетаскивание, заголовок под карточкой. Открытие в панели как в mymind: большой превью, заголовок, описание, теги, стрелки ←/→. Над доской фильтр по тегам.
- **Text** — одна карточка-документ как в Notion. Блоки Text, Heading 1–4, Bulleted / Numbered / To-do / Toggle list, Quote, Callout, Divider, Code, Emoji. Вставляются через `/` или markdown-сокращения: `# `, `## `, `- `, `1. `, `[] `, `> `, `" `, ```` ``` ````, `---`. У каждого блока ручка ⋮⋮: Turn into, цвет текста и фона, Duplicate, Delete.
- **Виджеты:** часы (аналоговые или цифровые, любой город), погода (Open-Meteo, прогноз на M/L), календарь (сегодня или месяц).
- **Sketch:** рисование на весь экран — перо, 8 цветов, 3 толщины, ластик, undo/redo. Линии сглаживаются (perfect-freehand).
- **Ссылки:** Notion, Miro, Figma, Pinterest, Instagram, TikTok, YouTube Shorts и любые сайты. **Файлы:** фото, видео, любые вложения.
- **Trash:** удалённые карточки и доски хранятся 30 дней, их можно восстановить или удалить навсегда.
- **Achievements:** значки с прогрессом и уведомлением при получении.
- **Публичные ссылки** на проект или доску (только просмотр). **Экспорт:** PDF, Markdown, HTML, CSV.
- Добавление: панель снизу или клавиша `/` (Text, Sketch, виджеты, медиа), вставка Cmd+V, drag & drop.
- Данные хранятся в IndexedDB браузера.

## Как устроено

- `server/shares.ts` — API публичных ссылок; обновлять снимок можно только с секретом, который хранится у владельца.
- `server/unfurl.ts` — плагин Vite: `/api/unfurl` достаёт OpenGraph/oEmbed (из браузера мешает CORS), `/api/img` проксирует превью. Превью скачиваются один раз и хранятся локально: ссылки CDN Instagram/TikTok протухают.
- `src/components/DocEditor.tsx` — редактор Text; `src/components/widgets/`, `src/components/sketch/` — виджеты и рисование; `src/components/CardDetail.tsx` — открытая карточка.
- `src/hooks/useWorkspace.tsx` — проекты, метаданные досок, Trash; `src/hooks/useBoard.ts` — карточки одной доски; `src/lib/router.ts` — hash-роутинг (`#/recent`, `#/drafts`, `#/project/:id`, `#/board/:id`, `#/trash`, `#/achievements`, `#/s/:token`).
- `src/lib/platforms.ts` — распознавание платформы по URL, embed-ссылки, размеры по умолчанию.
- `src/components/cards/*` — рендер текстов, медиа и ссылок.

API (превью ссылок и публичные ссылки) один и тот же код: в разработке его обслуживает Vite (`server/vitePlugin.ts`), на Vercel — функции из `api/`.

## Деплой на Vercel

- Проект собирается как Vite-приложение (`vercel.json`), функции `api/unfurl`, `api/img`, `api/shares`.
- Публичные ссылки хранятся в **Vercel Blob**: в проекте нужен Blob store (Storage → Create → Blob → Connect to project), он добавит переменную `BLOB_READ_WRITE_TOKEN`. Без неё шеринг отвечает 503, остальное приложение работает.
- Файлы из шеринга браузер загружает прямо в Blob (client upload), поэтому лимит тела запроса функций (4,5 МБ) видео не мешает.
- Локально без токена снимки пишутся в `.data/shares/`.
